§0 Conventions, metrics, provenance

0.1 Hardware and software

All sequence experiments ran on one laptop (Intel Core Ultra 5 135H, 14 cores / 18 threads, 16 GB) on the CPU PyTorch wheel under Python 3.13, with integer tensors stored in int64 and every narrow width (8/10/12-bit weights, 16-bit states, 32-bit accumulators, 12/16-bit mantissas) enforced by explicit range checks, saturation or wraparound. Matrix products above the int64-safe envelope are routed through a float64 GEMM path that is exact under asserted bounds and cross-checked against int64 (§8.1). Wall-clock times are therefore prototype times and say nothing about native low-bit hardware.

Part I — The system and the image experiments

§1 Exact reconstruction and per-layer updates

State v = [a, b]; coupling f(a) = Qt(max(Qt(aUᵀ), 0)Vᵀ); F(a, b) = [a, b + f(a)] mod 2bs; F−1(a, b) = [a, b − f(a)] mod 2bs. Qt is a per-row power-of-two right shift chosen from the row's magnitude bit length; the state halves are exchanged and permuted between couplings. The backward undoes the permutation, recomputes f(a) with the forward parameters, recovers b exactly, forms gU, gV and the input adjoint from the recomputed intermediates, and updates the layer only then (Figure 1). Gates that every configuration passes: inverse(forward(v)) = v bit-exact; reconstructed backward = cached backward for every parameter gradient (mantissa and exponent) and the final input adjoint; per-layer optimizer step = batched step over 6–8 updates.

§2 Shared-exponent adjoints and BlockSGD

Adjoints are (m, e) with value m·2e: a forward shift s gives e ← e − s, renormalisation moves shifts into e, additions align exponents first. BlockSGD (§0.3) block-normalises each parameter-gradient mantissa to 12 bits, accumulates, and emits ±1 when |acc| ≥ 2shift, keeping the residual; the stability condition is 2shift > 2param_bits − 1 (lr_bits ≥ 1). Momentum k: m ← m − rshift0(m, k) + gn; gn ← renorm(m, 12); decay 1 − 2−k (k = 7: (127/128)128 ≈ 0.37 of a buffer survives 128 steps, 0.10 survives 300). Split momentum routes the 16 source-pathway tensors (source embedding and positional table, encoder attention and FFN, decoder cross-attention Wq/Wk/Wv/Wo) to a BlockSGD instance with k = 0 and the 9 target-side tensors (target embedding and positional table, decoder self-attention, decoder FFN, output head) to an instance with k = 7 (Figure 5; equivalence gate in §20).

§4 Grouped couplings and Fashion-MNIST

§8 The causal-normalisation defect (original Appendix D)

8.1 Exact fast paths

Matrix products whose worst-case partial sums are provably below 253 run through float64 BLAS with a runtime guard; all 115 GEMMs of the measured configuration took the exact path with zero fallbacks, preserving the 34-item digits fingerprint, the digits gates, the JA–KO gates, the convolution/attention gates and every gradient mantissa/exponent. The output head's two-pass global shift and sparse hinge backward matched the dense path for chunk sizes 256–2048 (global shift, true logit, best-wrong value/index, gradient mantissas/exponents, token counts, hinge sum; only float64 logit s.d. differed, by 1.1 × 10−14).

8.2 Data and tokenizer controls

Six of 30 fixed acceptance sources were present in the Tatoeba/TED pool; normalised blocking removed 1,734 base pairs and reduced acceptance leakage 6/30 → 0/30. Two tokenizer bugs (a corpus-tag field trained as text; an alphabet-cap path evicting the word-boundary marker → spaces became <unk>) were fixed; limiting the alphabet to characters seen ≥ 20 times gave an exact 5,000-token vocabulary, mean source length ≈ 20 → 13.2 tokens, pairs under 30 tokens 34,966 → 70,808, training unknown rate 0.18%.

8.4 The defect and its fix

Order was raw = saturate(Q Kᵀ) → pow2norm(raw row) → score_act · mask: the row shift was chosen with future / PAD entries present. Future-target mutation at cut 3: blocks 0, 1 (cross) same; block 2 (self) raw/shift/S DIFF, out same; block 3 (FFN) same; blocks 4, 5 (cross) same; block 6 (self) DIFF through to out; block 7 (FFN) DIFF → earlier logits changed. Fix: compute the shift over valid entries only (self: keys j ≤ t and non-PAD; cross: non-PAD source keys), then force invalid entries to zero; multiplying by a 0/1 mask before the reduction is not equivalent for signed scores. Required post-fix gates (all later passed): future mutation at cuts 1/3/6, batch/PAD invariance, PAD-content mutation, existing exactness gates. The model was also found to have no positional encoding at all (§9.1). The BOS-anchor query transform (Q-row cosine dec4 0.844 → 0.418, dec5 0.765 → 0.507 in forward traces) passed the structural gates but was withheld.

§27 Established, hypothesised, open

Established (measured, with the files above). Bit-exact reconstruction and gradient-buffer-free per-layer updates with a constant activation working set across MLP, convolution, attention and encoder–decoder couplings. Shared-exponent adjoints rescue depth 16 on digits (backward-only intervention, five disjoint seed pairs). Grouped couplings with dispersing permutation: 78.7% at 1/8 cost. Learned integer positional tables and a row-coupled attention adjoint are necessary for small-set autoregressive memorisation. Momentum 7 memorises 512 pairs (472/512); split 7/0 reaches CASE A at 7,200 steps; 128 pairs 124/128; the routing is bit-identical to the canonical optimizer. The production gradient is unsaturated and sign-consistent with a wider backward to 0.3%. On 67k pairs: 26.0% token accuracy, chrF 7.08 / 7.86 single, 7.86 / 8.42 averaged (rows 1–400 / 401–1200); lr_bits 2 collapses source conditioning; averaging cycles do not compound. Float on the same split: 33.1% / 11.3 (CE), 28.7% / 9.8 (same head). On the 7.6k momentum-free run: deferred-firing debt causally degrades source-memory margin; TTL16 does not restore training.
Hypotheses (stated, not measured). Per-example source gradients cancel under momentum averaging while per-batch steps break the symmetry. The int8 clamp is the binding constraint at 67k. The 22–26% band is a ±1 sawtooth around a basin. The wide averaging window fails by mixing basins. The translation ceiling is set by data, then objective, then arithmetic.
Open. Resume-versus-restart control at 67k; a second 67k seed; a test split for the averaging gain; peak memory versus gradient checkpointing; momentum on the 7.6k trajectory; native low-bit kernels; any usable translation quality — no model here exceeds chrF 8.4 on unseen sentences and none produces exact matches on unseen sentences beyond 1/400.
